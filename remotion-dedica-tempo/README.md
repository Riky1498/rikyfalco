# Motion graphics – "Dedica tempo a te stesso"

Overlay Remotion sui primi 8" (200 frame @ 25fps) del video 1080x1920; il resto del video resta invariato.

1. Copia il video sorgente in `public/video.mp4`
2. `npm install`
3. `npx remotion render src/index.ts Main out/Dedica_tempo_motion.mp4 --codec=h264 --crf=17`
